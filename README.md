# EcoTrack

EcoTrack is a full-stack environmental observation platform built as a long-term learning project.

The goal is to combine software engineering, data analysis, and environmental science into a single application.

## Planned Tech Stack

### Frontend
- React
- TypeScript

### Backend
- Python
- Django
- Django REST Framework

### Database
- PostgreSQL

### Data Analysis
- pandas
- NumPy
- Matplotlib

### Developer Tools
- Git
- GitHub
- GitHub Actions
- VS Code
